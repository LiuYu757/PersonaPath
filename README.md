# PersonaPath

Dataset for **PersonaPath: Towards Knowledge-Centric Personalized Learning Path Planning**.

PersonaPath evaluates how language models plan personalized learning paths using learner goals, mastery states, and curriculum prerequisites. It combines synthetic learner profiles with hierarchical knowledge graphs and evaluates planning validity, adaptivity, and efficiency in basic and higher education.

## Data

- `profile-base/`: learner profiles for basic education.
- `profile-higher/`: learner profiles for higher education.
- `kg_output/`: structured curriculum knowledge graphs.

The data are provided as JSON files, with the original subdirectory structure preserved.
